# منصة "مجلس الوكلاء" — خطة البناء

منصة يضيف فيها المستخدم وكلاء ذكاء اصطناعي، يسمّيهم ويعطيهم تعليمات، ثم يرفع مشروعاً فيتناقش الوكلاء حوله، ويقترح "القائد" مهام لا تُنفَّذ إلا بعد موافقة المستخدم.

## الصفحات
1. **تسجيل الدخول / إنشاء حساب** (بريد وكلمة مرور).
2. **لوحة التحكم**: قائمة المشاريع + زر مشروع جديد.
3. **الوكلاء**: إضافة وكيل باسم (مثل: مدير الجودة، المهندس، القائد)، وصورة/لون، والمنصة (Claude، ChatGPT، Gemini مدمجة، أو Kimi وغيرها بمفتاح خاص)، والتعليمات (دوره وطريقة رده). تعيين وكيل واحد كـ"قائد".
4. **الإعدادات**: حفظ مفاتيح API الخاصة بالمستخدم (Kimi، OpenAI، Anthropic...) بشكل آمن.
5. **صفحة المشروع** (الأهم):
   - وصف المشروع + رفع ملفات (PDF، Word، صور، ملفات كود أو ملف مضغوط).
   - اختيار الوكلاء المشاركين.
   - **غرفة النقاش**: يكتب المستخدم سؤالاً، فيرد كل وكيل بدوره على التوالي، مع رؤية ردود من سبقه (الجودة يعلّق على رأي المهندس مثلاً). الردود تظهر مباشرة أثناء الكتابة.
   - **أوامر القائد**: يقترح القائد مهام محددة لوكلاء محددين، تظهر كبطاقات بزر "موافقة" أو "رفض".
   - عند الموافقة: ينفّذ الوكيل المهمة وينتج **تقريراً أو مستنداً أو ملفات كود** قابلة للتحميل.
   - **المخرجات**: قسم يجمع كل ما أنتجه الوكلاء.

## سير العمل

```text
رفع المشروع -> سؤال المستخدم -> نقاش الوكلاء بالتتابع
   -> القائد يقترح مهام -> موافقة المستخدم -> التنفيذ -> مخرجات للتحميل
```

## ملاحظة مهمة
Cursor وManus ليست لديهما واجهة محادثة عامة يمكن ربطها مباشرة؛ سيُدعم "مزوّد مخصص" لأي منصة متوافقة مع صيغة OpenAI (مثل Kimi وDeepSeek وGroq) بإدخال الرابط والمفتاح.

## التصميم
واجهة عربية بالكامل (من اليمين لليسار)، طابع داكن احترافي يشبه غرفة اجتماعات، لكل وكيل لون مميز في النقاش، ويعمل جيداً على الجوال.

## تفاصيل تقنية
- Lovable Cloud: حسابات، قاعدة بيانات، وتخزين ملفات.
- الجداول: `profiles`، `agents` (الاسم، المزوّد، النموذج، التعليمات، is_leader)، `projects`، `project_files`، `project_agents`، `messages`، `tasks` (الحالة: مقترحة/موافق/مرفوضة/منفذة)، `artifacts`، `provider_keys` (مفاتيح مشفرة، لا تُقرأ من المتصفح أبداً). صلاحيات RLS لكل مستخدم على بياناته فقط.
- النماذج المدمجة عبر Lovable AI (الافتراضي `openai/gpt-6-astra`، وClaude عبر واجهة Messages، وGemini). المفاتيح الخاصة تُستخدم من الخادم فقط.
- النقاش ومسار البث عبر server route لبث الردود؛ استخراج نص الملفات (PDF/Word/كود/zip) عند الرفع وتخزينه كسياق للوكلاء.
- القائد يُرجع مهام بصيغة منظمة (JSON) تُحفظ كمهام بانتظار الموافقة.
- المخرجات تُحفظ في التخزين وتُعرض للتحميل (Markdown/ملفات كود/ zip).

## مراحل التنفيذ
1. تفعيل Cloud، الحسابات، الجداول، الواجهة العربية الأساسية.
2. إدارة الوكلاء ومفاتيح المزوّدين.
3. المشاريع ورفع الملفات.
4. غرفة النقاش بالبث.
5. مهام القائد والموافقة والتنفيذ والمخرجات.
